STAYNEST - VERSI 1

Project website booking penginapan sederhana untuk tugas kuliah.

STRUKTUR FILE

index.html
    Halaman utama.

 penginapan.html
    Daftar penginapan, pencarian, filter harga, dan Google Maps.

detail.html
    Detail penginapan dan link lokasi Google Maps.

booking.html
    Form data pemesan, tanggal menginap, kamar, dan perhitungan total.

konfirmasi.html
    Halaman konfirmasi booking.

css/style.css
    Semua tampilan website. Sudah ditulis baris per baris agar mudah dibaca.

js/script.js
    Semua fungsi website. Sudah ditulis baris per baris agar mudah dipelajari.

CARA MENJALANKAN

1. Extract ZIP.
2. Buka folder StayNest_Versi_1_Map.
3. Klik dua kali index.html untuk membuka website di Google Chrome.
4. Buka menu Penginapan untuk melihat Google Maps.
5. Untuk tombol Lokasi Saya, lebih aman menjalankan project melalui VS Code + Live Server karena browser dapat membatasi geolocation pada file://.

GOOGLE MAPS

Website menggunakan Google Maps embed. Tombol Manado menampilkan pencarian hotel di Manado. Setiap kartu penginapan juga mempunyai link untuk membuka lokasi penginapan di Google Maps.

CATATAN

Data penginapan pada versi ini adalah data demo untuk keperluan tugas. Harga dan detail dapat dikembangkan lagi pada versi berikutnya.
